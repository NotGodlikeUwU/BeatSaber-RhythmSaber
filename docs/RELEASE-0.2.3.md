# RhythmSaber 0.2.3 — English documentation and publication preparation

Both platform READMEs, installation/build/debugging instructions, test plans, research notes, validation history and release notes are in English. PC README is renamed README.md; packaging references are updated. Historical binary/source archives remain unchanged for rollback.

Both embedded mod descriptions use the white judgement beam terminology. PC includes an English summary/description and a separately packaged BeatMods submission kit. It contains the exact release ZIP, source ZIP, checksums and human-readable publication instructions. It does not publish the mod, modify BSManager or assert catalog approval.

BSManager 1.6.0 discovers installed mods through BeatMods hashes; a private DLL manifest alone does not register a catalog entry. The exact release must be accepted into BeatMods for 1.40.8 before normal catalog detection and description display can be expected.

Gameplay, scoring windows/points, settings layout, rendering and submission guards are unchanged from 0.2.2. Existing OpenXR/VR launch parameters are untouched. Consult VALIDATION.md for build evidence and remaining live-test requirements.
