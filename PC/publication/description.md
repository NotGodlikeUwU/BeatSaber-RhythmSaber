# RhythmSaber

Score each accepted saber cut by its musical timing instead of swing angle or center accuracy. Normal notes retain a 115-point maximum. A white judgement beam marks the ideal plane, and native flying score popups show PERFECT, GREAT, GOOD, BAD or POOR with milliseconds or EARLY/LATE.

- Configurable timing windows, grade points, text size and beam appearance.
- Optional timing statistics and separate local results.
- Ordinary custom songs and native Arc/Chain scoring with each note type's own maximum.
- Observed-motion measurement for Noodle/Mapping maps; install the extensions required by the map.
- Native color, direction, bad cuts, physical misses, combo and multipliers remain intact.

**Target:** PC Beat Saber 1.40.8 (1.40.8_7379), BSIPA. Requires BeatSaberMarkupLanguage, SiraUtil and BS Utils. Quest QMODs are separate.

**Local play:** online score submission and original personal-best updates are blocked during RhythmSaber play. Audited BeatLeader 0.9.33 and ScoreSaber 3.3.17 DLLs have additional local guards; unknown DLL hashes prevent activation. See README for exact hashes and required live tests. Other leaderboard/export mods are not automatically covered.

**Measurement limits:** animated future crossings are predicted and marked `~`; unmeasurable motion scores zero. Frame uncertainty remains; exact sub-frame impact timing and every third-party mod combination are not claimed. Multiplayer, Campaign and Tutorial keep original scoring.

Install the release ZIP through BSManager's Import mods or extract it into the 1.40.8 game folder. Open Settings → Mod Settings → RhythmSaber. Changes apply next song. Disable RhythmSaber for original scoring next song/restart.

Public release 0.1 (manifest 0.1.0) includes the latest development changes: a compact tab selector with full-panel settings pages, configurable timing points and smaller failure labels. Documentation is in English. Previous gameplay was user-confirmed; the new layout and online-submission matrix still require fresh live VR validation.
